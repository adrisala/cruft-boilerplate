# Boilerplate

Standard boilerplate used to create a new service within the Ansible
Automation Platform.

## Usage

To use this cookiecutter/cruft template:

```bash
cruft create https://github.com/adrisala/cruft-boilerplate.git
```

## Development

If you want to modify this template, you need to install it in editable mode first:

```bash
pip install -e .
```

This makes the custom Jinja2 extension (`PackageNameExtension`) available for cookiecutter to use.
